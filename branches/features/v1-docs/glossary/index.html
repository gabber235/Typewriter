Glossary

Hover any dotted term in the documentation to see its definition, or browse all terms below.

Audience

audienceaudiences

An audience is the set of players a manifest entry currently applies to. Display entries show their content to their audience; filter entries narrow the audience passed on to their children.

Book

bookbooks

A book is a collection of pages inside a realm. Books are listed in the panel’s Library and each has a title, an icon, a colour and tags.

Criteria

criteriacriterion

Criteria are the conditions on an entry: a fact, an operator and a value. Every criterion on an entry must pass before the entry runs — and if one fails, the entry’s modifiers do not run either.

Cue

cuecuessegmentsegmentskeyframekeyframes

A cue is a block on a scene’s track: either a segment with a start and end frame, or a keyframe at a single frame. Cues on one track cannot overlap. 20 frames make one second.

Entry

entryentries

An entry is the smallest building block of Typewriter content: a dialogue, an action, an event, a scene cue, each provided by an extension.

  • Static entries define reusable data, like NPC definitions.
  • Triggerable entries run as part of an interaction.
  • Manifest entries stay active for an audience.

Extension

extensionextensions

An extension is a modular add-on that provides new entries to Typewriter. Extensions are .jar files placed in the plugins/Typewriter/extensions folder. The BasicExtension ships the essential entries most servers need.

Fact

factfacts

A fact is a number Typewriter remembers about a player — quest progress, a choice they made, how many of an item they carry. Every fact is an integer, read by criteria and written by modifiers.

Group entry

group entrygroup entries

A group entry decides who shares a fact’s value: each player individually, everyone in a world, everyone on the server, or a grouping an extension defines such as a region or a party.

Inspector

inspector

The inspector is the panel pane where you edit the selected page element: its name, its fields and the operations available on it.

Interaction

interactioninteractions

An interaction is what a player experiences in game: a dialogue, quest or scene composed of connected entries. A player runs one interaction at a time; it starts when a trigger fires and follows the flow you build on the page.

Manifest

manifestmanifests

A manifest is a page type whose entries describe state that should hold while a condition is true, instead of running once: audiences, displays and filters.

Modifier

modifiermodifiers

A modifier changes a fact after an entry has run. It sets, adds to, subtracts from or multiplies the stored value.

Organization

organizationorganizations

An organization is the top level of the panel. It has members, roles and join codes, and owns realms and the services connected to them.

Page

pagepages

A page holds page elements inside a book. Every page has a type — Sequence, Static, Scene or Manifest — which decides what it can hold and how the elements connect, plus a chapter and a priority.

Page element

page elementpage elements

A page element is anything placed on a page: an entry, a group of entries, or, on a scene page, a cue. Elements are the nodes you see on the graph and the tracks you see on the timeline.

Realm

realmrealms

A realm is the content space a Minecraft server connects to. Realms belong to an organization and hold books. A server joins a realm with the registration token printed in its console.

Road network

road networkroad networks

A road network is a graph of nodes and edges Typewriter uses to path efficiently between two distant points, so NPCs can walk sensible routes across your map instead of computing paths block by block.

Scene

scenescenescinematiccinematics

A scene is a page type for timed content: camera paths, animations and cutscenes built from cues placed on tracks. In extension code the scene family is still called cinematic.

Sequence

sequencesequences

A sequence is a page type whose entries play one after another as an interaction unfolds. Most dialogues and quests are built on sequence pages.

Static

static

A static page holds entries that reference data which doesn’t change over the lifetime of the program, such as NPC definitions or item templates.

Track

tracktracks

A track is the timeline row of one entry on a scene page, where its cues are placed and timed. Time is measured in frames: 20 frames equal 1 second.

Trigger

triggertriggers

A trigger is the link between two entries: when one finishes, the entries it triggers run next. Chaining triggers on a sequence page is how an interaction plays out step by step.
