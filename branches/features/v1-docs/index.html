What you build

Dialogue, quests, scenes and NPCs

Each one is a page in the panel. Pick a page type, place entries on it, connect them.

  • NPCs talk in chat, players answer with options, and each answer can lead somewhere else.

  • Objectives count kills, distance and blocks, show progress in the sidebar, and hand over to the next objective when done.

  • Camera moves, titles, particles and spoken lines on one timeline, timed to the frame.

  • Define an NPC once, then place instances that patrol a road network, look at players and react when clicked.

How it works

Three steps from a fresh server to a talking NPC

  1. 1

    Step 1: Connect your server to a realm

    Install the plugin next to PacketEvents and start the server. The console prints a ten-character registration token; paste it into the panel under Services → Connect a Service and the server joins your realm.

  2. 2

    Step 2: Build pages in the panel

    Create a book in the Library, add pages, and place entries on them. Sequence pages hold dialogue and actions, scene pages hold timed cues, manifest pages hold audiences that stay active while a condition is true.

  3. 3

    Step 3: Play it on your server

    Players talk to your NPCs in chat, pick options, complete objectives and watch scenes on the server connected to the realm. Nothing to install on the client.

The panel

One editor for graphs and timelines

Sign in, open your realm, and every book, page and entry is a click away. Nothing to install. Click a pin to see what each part of the editor does.

  • Scenes on a timeline

    Scene pages swap the graph for a timeline: one track per entry, cues placed by frame, twenty frames per second.

  • Search with selectors

    Press S or / and search the whole realm with key:value selectors. Results group into entries, definitions, pages, books and tags.

  • Dark
    Light

    Dark or light

    The panel follows your system theme, and so do these docs. Drag the handle to compare.

Player memory

Stories that remember each player

Every player gets their own version of your story. One page can greet a stranger, thank the person who brought the iron and turn away someone who already claimed the reward. Typewriter stores facts per player; criteria read them before an entry runs and modifiers change them afterwards.

What it can remember

Each is a fact entry you add once, the purple ones in the panel. Typewriter keeps the values per player, per world or for the whole server, and saves them for you.

Forever
Joined before, finished the quest, took the reward: kept until you reset it.
Until logout
Time played this session, warnings given tonight: gone when the player leaves.
For a set time
The guard stays angry for twenty minutes, then forgets about it.
Counting down
Daily rewards and cooldowns keep ticking while the player is offline.
On a schedule
Weekly resets and shop opening hours, cleared by a cron expression.
Read from the world
Items in the inventory, balance, permissions, WorldGuard region: looked up live, nothing stored.

For developers

Every entry is a Kotlin class

Show the whole classHide the whole class

An extension is a JAR of Kotlin classes marked @Entry. The panel reads the annotation for the name, description, colour and icon, turns the constructor parameters into inspector fields, and the server runs the body. The ten extensions that ship with Typewriter, about five hundred entries, are written exactly like this one.

Questions

Do I need to know how to code?

No. Everything on this page is built in the panel by placing entries and connecting them. Kotlin only comes in when you write your own extension because the shipped entries do not cover a case.

Is 1.0 ready to use?

Not yet. Typewriter 1.0 is in active development: the new panel, the realm service and these docs are being built in the open. Expect gaps, and ask on the Discord for the current state before moving a live server to it.

Do I host the panel?

No. The 1.0 panel is a hosted web app. You sign in, create an organization and a realm, and connect servers to it with a registration token. The plugin is the only thing you run.

Is it open source?

It is source-available. The code is on GitHub under the Typewriter Software License, which allows use and contribution but not redistribution or modification outside the project.

Anything else

Questions get answered on the Discord; bugs and feature requests go to GitHub issues.
