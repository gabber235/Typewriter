This guide walks you through setting up a development environment for building Typewriter extensions.

## Prerequisites

- A Java development environment (JDK 21 or newer)
- A Paper Minecraft server for testing
- Familiarity with the [core concepts](/docs/01-typewiter) of Typewriter

## Next steps

More developer documentation is on its way. In the meantime, explore the [Typewriter repository](https://github.com/Gabber235/typewriter) to see how the built-in extensions are structured.
