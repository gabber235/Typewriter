An **entry** is the smallest building block of Typewriter content. Pages are
made up of entries: dialogues, actions, events, cinematics, and more, each
provided by an extension.

- **Static entries** define reusable data, like NPC definitions.
- **Triggerable entries** run as part of an interaction.
