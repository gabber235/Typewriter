---
title: Entry
aliases: ["entry", "entries"]
---

An **entry** is the smallest building block of Typewriter content: a dialogue,
an action, an event, a scene cue, each provided by an
[extension](/glossary/#extension).

- **Static entries** define reusable data, like NPC definitions.
- **Triggerable entries** run as part of an [interaction](/glossary/#interaction).
- **Manifest entries** stay active for an [audience](/glossary/#audience).
