title: Page
aliases: ["page", "pages"]
---

A **page** holds [page elements](/glossary/#page-element) inside a
[book](/glossary/#book). Every page has a type — [Sequence](/glossary/#sequence),
[Static](/glossary/#static), [Scene](/glossary/#scene) or
[Manifest](/glossary/#manifest) — which decides what it can hold and how the
elements connect, plus a chapter and a priority.
