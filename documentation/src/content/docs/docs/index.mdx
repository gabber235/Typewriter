Typewriter 1.0 is being documented from scratch. This section will cover installing the plugin, working in the web panel and building stories. For now it holds the [writing syntax](./01-syntax.md) reference that every future page is built with.
:::

## What will live here

- **Getting started**: installing the plugin, connecting your server to a :term[realm], the panel layout.
- **Creating stories**: interactions, :term[scenes], facts, entities, quests and road networks, as step-by-step tutorials.
- **Concepts**: :term[organizations], :term[books], :term[pages], :term[entries], :term[triggers], :term[facts] and :term[criteria] explained once, properly.
- **Helpful features** and **troubleshooting**.

## Writing a page

Every page is Markdown with a small set of custom directives on top: keycaps, copyable commands, site variables, glossary terms, collapsibles, gated sections, decision wizards, annotated screenshots and comparison sliders. The [syntax reference](./01-syntax.md) shows each one with its source and the rendered result on a single page.

Building extensions instead? Head to the [developer documentation](../develop/index.mdx).
