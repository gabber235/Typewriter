EXTRACTION METHODOLOGY
================================================================================

Data Extracted for Each @Entry:
✅ Entry ID (e.g., "withdraw_balance")
✅ Display Name (e.g., "Withdraw Balance")
✅ Icon Reference (e.g., "majesticons:money-minus")
✅ Description (from class javadoc)
✅ Field Names (all declared fields)
✅ Field Labels (humanized from camelCase)
✅ Help Text (@Help annotations)

JSON Output Format:
{
  "{namespace}.{entry_id}.title": "Display Name",
  "{namespace}.{entry_id}.description": "Description",
  "{namespace}.{entry_id}.fields.{field}.label": "Field Label",
  "{namespace}.{entry_id}.fields.{field}.help": "Help Text"
}
