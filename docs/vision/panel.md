# Panel

## What it is

The visual editor where content is created. It reaches engines through the realm.

It comes in three forms: a **web panel** hosted on Typewriter Cloud, **desktop** applications, and **mobile** applications.

- **Desktop is the primary way** to use Typewriter.
- **Mobile can do everything**, if not always as nicely. Almost everything is already mobile friendly, and it should stay that way; people do edit on phones.
- **Everything is keyboard driven**: everything can be done with a keyboard.

Related panel features:

- Runs interactive tutorials through the [panel engine](engines.md).
- Lets people look up stored data, including where a value came from (which group, and which protagonist wrote it) ([data storage](data-storage.md)).
- Shows **live formula values** for a specific protagonist (during the closed beta, not at the start).
- **Account linking**: knows which panel account belongs to which Minecraft account. Needed for live values and for redoing **content capture**: capture from a default protagonist, or pick one from a list of online protagonists. Requires communication between the panel and engines.
- May host an AI assistant that builds content from a request ([AI](ai.md)).

## Who it serves

Content creators and server owners; panel users learning Typewriter.

## Why

Configuration through a visual tool is how Typewriter content is made.
