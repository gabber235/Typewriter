# Pricing

## What it is

Which parts of Typewriter are free and which are paid.

**The core is always free.** People should be able to start with Typewriter and grow with it.

| Part | Model |
| --- | --- |
| Core | Free, always |
| Multi server support | Paid add on, one time purchase. Needed for **more than one engine** |
| Production realm mode | Free, but only useful with multi server (see [realm-modes.md](realm-modes.md)) |
| Resource pack support | Paid add on, one time purchase |
| AI features | Credits, or owners' own API keys; undecided |
| Paid parts of free extensions | Behind feature flags (see [marketplace.md](marketplace.md)) |
| Small marketplace purchases | Credits, because payment fees would eat prices that small |
| Cloud backups and sync | Monthly fee (someday) |

Who owns a one time add on is not decided. Owned by the user and valid in every organization they are in is **rejected** (too generous). Two candidates remain:

| | Organization owned | User owned, assigned to one organization at a time |
| --- | --- | --- |
| Buyer leaves | Server keeps the add on | Buyer can move it; the old organization loses it |
| Fit | Matches what is licensed: the server setup | Buyer keeps what they paid for |
| Cost to build | Low; transfers through support | Assigning and cooldown rules |

## Who it serves

Server owners and content creators (free start, pay as they grow), the Typewriter team (sustainable income).

## Why

A free core lets people adopt Typewriter and grow with it. Paid add ons cover features that bigger setups need. Credits make small or usage based payments viable.
